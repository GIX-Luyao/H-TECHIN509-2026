# Example scope — TeamGuide

## Objectives

Help a new teammate find answers in a fictional team's onboarding documents.

Example questions:
- How do I reset my password?
- Where do I request equipment?
- What should I complete before my first team meeting?

## The gap / need

Onboarding instructions are spread across several documents. The user needs an answer with a source they can check. Document retrieval fits because these questions concern written procedures.

## Key deliverables

A chatbot that answers questions from five synthetic onboarding documents, cites its sources, and says it does not know when evidence is missing. The first version will not access employee accounts or submit requests.

## Data requirements & constraints

Use fictional documents written for this project. Exclude real names, credentials, employee records, and internal company material. Review every file and staged change before pushing.

## Success measure

Prepare eight answerable questions and two unsupported questions. At least seven answerable questions must return correct answers with the right sources. Both unsupported questions must produce an explicit “I don't know” response.

## Peer review and revision

Before: answer any HR or IT question. After: answer onboarding questions from five synthetic documents. A reviewer pointed out that the original scope had no clear data boundary.
