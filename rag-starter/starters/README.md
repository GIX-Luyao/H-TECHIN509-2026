# `starters/` — blanked files for the in-class faded exercises

Each file here is a **faded version** of a finished file in `ribot/`: the structure is given,
but the load-bearing lines are replaced with `# TODO`. You fill the blanks in class.

If you get stuck, the matching file in `ribot/` is the **known-good reference** — peek at it,
or copy it over to get unblocked, then keep going.

| Starter | Fills in | Reference |
|---------|----------|-----------|
| `week3_memory.py` | the conversation loop + `.append` | `ribot/chatbot.py` |
| `week5_retriever.py` | `cosine_similarity` + nearest-chunk loop | `ribot/similarity.py`, `ribot/build_index.py` |
| `week6_build_index.py` | chunk → embed → store → query | `ribot/build_index.py` |
