# HMSTI 509 — Python Programming for Personal AI Assistants (2026)

Learn Python by building a personal AI assistant, from a first conversation to an agent that searches documents and uses tools.

| Module | What it's about |
|---|---|
| [1 — Ship It: Your Assistant Is Alive](week-1/) | Set up your environment, run the assistant, and explore its main parts and safety habits. |
| [2 — Talking to the Model](week-2/) | Use variables, string methods, and f-strings to build your assistant's profile prompt. |
| [3 — Assistant's Memory](week-3/) | Build conversation memory and a chat loop with lists, dictionaries, conditionals, and loops. |
| [4 — Reusable Parts](week-4/) | Organize code into functions, handle errors, and save and load structured data with JSON. |
| [5 — Why Search Feels Smart](week-5/) | Understand embeddings and cosine similarity; build a retrieval loop in Python and NumPy. |
| [6 — Give the Bot a Library](week-6/) | Load files, split text into overlapping chunks, embed and store them, and retrieve relevant passages. |
| [7 — Classes + Unit Testing](week-7/) | Build chatbot and logger classes, manage conversation memory, package tools, and test their behavior. |
| [8 — Build a Tiny Agent](week-8/) | Coordinate a model and document search in a bounded loop, explore prompt injection, and connect local or API models. |
| 9 — Thanksgiving | No class due to Thanksgiving. |
| [10 — Ship Your Agent](week-10/) | Extend the agent loop to multiple tools, explore tool selection, and harden the agent against failures. |

Each module includes a lesson notebook; some also include studio exercises or supporting code. The shared assistant code lives in [`rag-starter/`](rag-starter/).
